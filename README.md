### ✨ 能做什么

- 主题、笔记、PPTX 或已有 HTML deck → 单文件 HTML 演示文稿，内联 CSS/JS，零 npm、零构建工具
- 固定 1920×1080 的 16:9 舞台整体等比缩放至视口，手机上也保持 16:9，不用响应式断点重排内容

- 三种模式：从零新建、PPT/PPTX 转换、增强已有 HTML deck（先读懂再增强，遵循模式 C 修改规则）
- 交付后可部署为任何设备（含手机）可打开的可分享 URL，或导出 PDF 用于邮件、Slack 与打印；内置 prefers-reduced-motion 支持

## 🇬🇧 English

Creates zero-dependency, animation-rich HTML web slides from scratch, a rough outline, complete content or a PowerPoint file — one HTML file with inlined CSS/JS and no npm or build tools. Inputs can be a topic, notes, a PPTX or an existing HTML deck; the output is a distinctive, viewport-safe single-file HTML that can be exported to PDF or deployed as a shareable URL. Style is not described in words: visual previews let you pick by looking, and the full design spec is read only after you choose one of the 34 bold templates. Every deck uses a fixed 1920×1080 16:9 stage scaled uniformly to the viewport, staying 16:9 on phones with no breakpoint reflow of slide content. It first asks whether the deck is mainly for speaking or for reading, then designs in a low-density presenting mode or a high-density reading mode; three modes cover new decks, PPTX conversion and enhancing an existing deck.

### ✨ What it does

- Topic, notes, PPTX or existing HTML deck → a single-file HTML presentation with inlined CSS/JS and no npm or build tooling
- A fixed 1920×1080 16:9 stage scales uniformly to the viewport, staying 16:9 even on phones with no responsive breakpoint reflow of content
- Visual style previews let you choose by looking across 34 bold templates, with the full design spec read progressively afterwards — deliberately avoiding generic AI-looking aesthetics
- Two content densities: presenting mode with one idea per slide, large type, strong hierarchy and at most 1-3 bullets; reading mode with 4-8 bullets or 4-6 cards per slide plus grids, tables and annotations
- Three modes: build from scratch, convert PPT/PPTX, or enhance an existing HTML deck (read and understand it first, following the mode C modification rules)
- After delivery it can deploy as a shareable URL that opens on any device including phones, or export to PDF for email, Slack and print, with prefers-reduced-motion support
